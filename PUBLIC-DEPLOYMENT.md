# Public deployment

Superseded 11 September 2026. The site is built by `scripts/build.py` for one
environment at a time and only that artifact is published. Web3Forms is retired,
so no form key or repository secret is needed.

Read `_site/README.md`.

One-time GitHub setting: **Settings, Pages, Build and deployment, Source: GitHub
Actions.** Until that is set, GitHub keeps publishing the whole branch.
